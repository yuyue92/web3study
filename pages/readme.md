**一个智能路由功能的交易所**

CryptoSwap DeFi应用，前端与智能合约交互的完整流程，包含以下几个核心环节：
- 钱包连接层：负责与MetaMask等钱包的连接和账户管理；
- 合约抽象层：封装工厂合约、路由合约、交易对合约的交互；
- 业务逻辑层：实现代币交换、流动性管理等DeFi核心功能；
- 状态管理层：使用react context管理全局状态；
- 错误处理层：处理各种交易异常和用户体验优化；

- 核心交互流程：
   - 代币交换：获取报价 → 代币授权→ 执行交换→ 交易确认；
   - 流动性管理：添加或移除流动性→ LP代币管理→ 收益计算；
   - 实时数据：余额查询→ 价格获取→ 储备量监控；
