合约与合约之间的调用通常发生在区块链平台上，在智能合约领域，智能合约是一种自动化合约，可以编程执行特定的功能，并且它们之间可以相互调用；

在以太坊这样的区块链平台上，智能合约之间的调用是通过合约地址和函数调用来实现的：
- 获取被调用合约的地址：在调用合约中先需要获取目标合约的地址；
- 定义接口： 为了与目标合约交互，需要在调用合约中定义一个接口， 这个接口包含目标合约的函数签名和返回值类型；
- 调用函数： 通过目标合约的地址和定义的接口，在调用合约中调用目标合约的函数；
- 处理返回值：如果被调用的合约函数有返回值， 带哦与合约可以处理这些返回值；


合约调用的示例：

合约B：
```
pragma solidity ^0.8.0;
contract ContractB {
  uint public value;
  function setValue(uint256 _value) public {
    value = _value
  }
  function getValue() public view returns(uint256) {
    return value;
  }
}
```

合约A:
```
pragma solidity ^0.8.0;
// 引入合约B的ABI
import "./ContractB.sol";
contract ContractA {
  ContractB public contractB;    //创建合约B实例
  constructor(address _contractB_Address) {
    contractB = ContractB(_contractB_Address)   //实例化合约B
  }
  function setValueInContractB(uint256 _value) public {
    contractB.setValue = _value;
  }
  //从合约B中获取值；
  function getValueFromContractB() public view returns {
    return contractB.getValue();
  }
  
}
```

在上面的例子中，合约A实例化了合约B，并且可以调用合约B中的函数；在哦鼓噪函数中，合约A接受合约B的地址作为入参，然后通过调用 setValueInContractB 和 getValueFromContractB，合约A可以在合约B中设置值和获取值。
